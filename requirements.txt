# ============================================================================
#  Runtime dependencies — NO-BUILD / flat list, unpinned so pip takes whatever your index has.
#
#  There are NO editable (`-e`) installs here: the vendored code (secure_bench, camel, the
#  WebArena harness) runs straight from PYTHONPATH (set by env.sh), so pip does NOT need `hatchling` or
#  any build backend — this installs cleanly from a locked-down private index.
#
#  Install (from the artifact root, venv activated):
#    git clone https://github.com/web-arena-x/webarena fetched/webarena_official   # (setup.sh does this)
#    pip install -r requirements.txt
#    playwright install chromium
#  Point pip at your index if needed:  pip install --index-url <your-index> -r requirements.txt
#
#  If a run later dies with `ModuleNotFoundError: X`, that package just isn't on your index yet —
#  install it (`pip install X --index-url <your-index>`) and add it here. This list is trimmed to what
#  our arms actually import.
#  No GPU needed (no torch/transformers here — unused by our arms).
# ============================================================================
